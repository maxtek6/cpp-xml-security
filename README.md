# cpp-xml-security

Active fork of the `xml-security-c` framework.

## About

The `xml-security-c` library was part of the Apache Satuario project, 
but it was later abandoned. It was then maintained for internal usage 
by the Shibboleth Project, but it is no longer actively developed.

The goal of this fork is to support the original version, while also 
adding support for additional features and updates.
